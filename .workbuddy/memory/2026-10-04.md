# 2026-10-04 · Hub-develop 官网重构（多页面 + 内容配置化 + tiouo 页脚）

## 背景需求（仓仓）
1. 页脚要用 tiouo.cc 那种「高级效果」。
2. 希望用**几个统一的文本/配置文件**控制整站显示内容。
3. 不要偷懒只写一个页面，多写几个。

### 1) 内容收口（核心）
- `src/content/site.ts` —— 全站文案唯一来源：`brand / nav / socials / hero / about / contact / footer / seo`。

## 踩坑 / 约定
- **SPA 深链接**：GitHub Pages 无 rewrite，history 模式下直接访问 `/projects/mchub` 会 404。用 `public/404.html` 把原始 href 存 sessionStorage → 跳回仓库根；`index.html` head 最前面读回并 `history.replaceState`。curl 只会看到 HTTP 404（响应体是 404.html），**必须用真实浏览器验证**（本次验证 `location.pathname` = `/hub-develop-web/projects/mchub`、`h1` = MChub，通过）。
- **整页截图 vs 滚动入场动画**：有 IntersectionObserver + `opacity:0` 时，`screenshot --full` 首屏以下区块是透明的。先 `eval` 注入 `.reveal{opacity:1!important}` 再截。
- **agent-browser 截图 flag 是 `--full`**（不是 `--full-page`）；`set viewport W H` / `set device "iPhone 12"` 可做响应式自查。
- **后台预览服务会被回收**：`npm run preview &` 在该次 Bash 调用结束即被清掉，「起服务 + 截图」必须写在同一次 Bash 调用里，否则 `ERR_CONNECTION_REFUSED`。
- `<ol>` 不会吃到全局 `ul { list-style:none }` 的重置，漏出 `1. 2. 3.`；已把全局重置改成 `ul, ol`。
- 构建校验顺序：`npx vue-tsc --noEmit`（需 `@types/node`，否则 `node:url` 报错）→ `npm run build`。
