## 踩坑 / 约定
- **SPA 深链接**：GitHub Pages 无 rewrite，history 模式下直接访问 `/projects/mchub` 会 404。用 `public/404.html` 把原始 href 存 sessionStorage → 跳回仓库根；`index.html` head 最前面读回并 `history.replaceState`。curl 只会看到 HTTP 404（响应体是 404.html），**必须用真实浏览器验证**（本次验证 `location.pathname` = `/hub-develop-web/projects/mchub`、`h1` = MChub，通过）。
- **整页截图 vs 滚动入场动画**：有 IntersectionObserver + `opacity:0` 时，`screenshot --full` 首屏以下区块是透明的。先 `eval` 注入 `.reveal{opacity:1!important}` 再截。
- **agent-browser 截图 flag 是 `--full`**（不是 `--full-page`）；`set viewport W H` / `set device "iPhone 12"` 可做响应式自查。
- **后台预览服务会被回收**：`npm run preview &` 在该次 Bash 调用结束即被清掉，「起服务 + 截图」必须写在同一次 Bash 调用里，否则 `ERR_CONNECTION_REFUSED`。
- `<ol>` 不会吃到全局 `ul { list-style:none }` 的重置，漏出 `1. 2. 3.`；已把全局重置改成 `ul, ol`。
- 构建校验顺序：`npx vue-tsc --noEmit`（需 `@types/node`，否则 `node:url` 报错）→ `npm run build`。

## 追加：全站字体换成阿里妈妈方圆体 VF（仓仓要求）
- 字体：**阿里妈妈方圆体 VF（Alimama FangYuanTi VF）**，阿里免费可商用（含网页/App 内嵌）**双轴可变中文字体**，字重轴 `wght` 200–700、方圆轴 `BEVL` 默认 100（圆体）。用 fonttools 读过 woff2 的 `fvar` 表确认过，别凭文件名以为它只是 Thin。
- 来源：npm 包 `@fontpkg/alimama-fang-yuan-ti-vf@1.0.5`（`npm pack` 取 `AlimamaFangYuanTiVF-Thin.woff2`，2.93MB，VF 全字重就是这一个文件）。官方 `fonts.alibabadesign.com` 直链 **403**，不可用。
- 落地：字体放 **`src/assets/fonts/AlimamaFangYuanTiVF.woff2`**，`style.css` 里 `@font-face{src:url("./assets/fonts/...") format("woff2-variations");font-weight:200 700;font-display:swap}`，`--sans` 首位改为 `"Alimama FangYuanTi VF"`。
  - **放 src/assets 而非 public/ 是关键**：Vite 会处理 CSS 里的 `url()` 并按 `base` 自动改写路径（dev 与 `/hub-develop-web/` 线上都对），放 public 反而要手动拼 base。
- `font-weight: 800/850` 会被可变轴钳到 700（真实字重、无假粗），故未逐个改。
- 授权：`public/FONT-LICENSE.txt` 附说明。
- 线上验证（权威）：`document.fonts.check('700 16px "Alimama FangYuanTi VF"') === true`、`[...document.fonts]` 里有 `Alimama FangYuanTi VF 200 700 loaded`、body computed fontFamily 首位是该字体。提交 `1af55ac`。
