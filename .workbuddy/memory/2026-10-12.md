## MChub 官网改用阿里妈妈方圆体（AlimamaFangYuanTi）
- 背景：桌面端 MChub（Avalonia）早已用 AlimamaFangYuanTi（src/MChub/Assets/Fonts/*.ttf，经 Styles/Fonts.axaml 全局应用）。官网（MChub.Web/site-src，Vite，挂在 mchub.code.hub-develop.top）此前用系统字体栈，本次统一换上同款字体做品牌一致性。
- 做法：
  - 字体文件取自桌面端 `src/MChub/Assets/Fonts/AlimamaFangYuanTi-{Regular,Bold}.ttf`，复制到 `MChub.Web/site-src/public/fonts/`。
  - 用 fonttools 转 woff2（Regular 907KB / Bold 786KB，原 ttf ~2.6MB），woff2 优先 + ttf 回退，`font-display:swap`。
  - `src/styles/global.css` 顶部加 `@font-face`，body 字体栈改为 `'AlimamaFangYuanTi', system-ui, -apple-system, 'PingFang SC', 'Microsoft YaHei', sans-serif`。
  - `npm run build`（managed node 22）生成 dist；`rsync -a --delete --exclude=CNAME dist/ wwwroot/` 同步（保留 CNAME=mchub.code.hub-develop.top）。
- 提交：local main `d557bdd`，仅含 MChub.Web 12 个文件（未动桌面端其它未提交改动）。
- 推送成功：仓库已迁移到 Hub-code-develop/MChub（git push 报 "repository moved" 并重定向）。沙箱内 `env -u HTTP_PROXY ... git push` 直连成功。commit d557bdd 已上 main。
- 部署验证：发布官网 workflow 跑绿（12s），live 站点 CSS 已含 @font-face、root 200、/fonts/AlimamaFangYuanTi-Regular.woff2 返回 200(font/woff2,907KB)。mchub.code.hub-develop.top 已用上阿里妈妈方圆体。

## 环境提示（本机 git 推送）
- 本机 git 走 HTTP_PROXY/HTTPS_PROXY 环境变量（127.0.0.1:7892），该 Clash 上游断开时 push 会 502；`gh` 不受影响（能直连 GitHub）。沙箱内 git 直连被 kill(137)/超时。临时推送需 `env -u HTTP_PROXY -u HTTPS_PROXY ... git push` 且依赖代理上游在线。
