# 2026-10-05 工作记录

## Hub-develop 官网：i18n 英文→中文切换卡死修复

- **根因**：`src/content/site.ts` 原写法 `export const site = reactive(siteZH)` 让 `site` 与
  源对象 `siteZH` 是**同一目标**;`watch(locale)` 里 `site.hero = siteEN.hero` 的赋值会**写回源对象**,
  把中文源 `siteZH.hero` 永久毒化成英文引用。第一次切换(zh→en)正常,但之后任何切回 zh 的
  watch 从 `siteZH` 读到的 `hero` 已是英文 → 永远卡英文。
  (`projects` 用 `splice` 原地改、`ui.ts` 每次读 `locale.value`,不受影响,故只有 `site` 在 en→zh 失效。)
- **修复**：`site` / `projects` 均改为**随 `locale` 派生的 `computed`**(`computed(() => locale==='en'?siteEN:siteZH)`),
  切换语言只是换一份新配置对象,绝不写回源 → ZH↔EN 任意方向都正确。移除原 `reactive`+`watch` 写回方案。
- **i18n 文件化**：UI 文案(按钮/标签/标题)从 `src/i18n/ui.ts` 内联字典抽到独立文件
  `src/i18n/locales/zh.ts` 与 `src/i18n/locales/en.ts`,`ui.ts` 改为引入并提供 `t()`。
- **设备级语言记忆**：`src/i18n/index.ts` 的 `localStorage['hub-develop-locale']`(detectLocale 优先读)
  保持不变——本设备切到哪种语言,刷新后沿用该语言。
- **验证**：用 `vite-node` 跑了 ZH→EN→ZH→EN→ZH 双向复现,确认全部正确; `vue-tsc` 类型检查通过;
  `vite build` + 部署 `gh-pages`(`/private/tmp/hub-ghpages` worktree,CNAME=hub-develop.top)已推送。
- 模板里 `site.x` 因顶层 ref 自动解包**无需改动**;脚本侧访问补了 `.value`
  (App.vue / router / Hero / About / Contact / Footer / Home / Projects / vars.ts)。

## Hub-develop 官网：语言切换改为下拉 + 扩到 4 语言(中/英/日/韩)

- **需求**：原「中/EN」按钮组装不下更多语言 → 换成下拉选择;并支持更多语言(整站正文也全翻译)。
- **架构(可扩展 N 语言)**：
  - `src/i18n/index.ts`：`LOCALES` 用 `as const` 注册表 `{code,native,htmlLang}`，
    `Locale` 类型 = `(typeof LOCALES)[number]['code']`(改一处即扩类型)；
    `DEFAULT_LOCALE='en'` 兜底；`detectLocale` 按 `LOCALE_CODES` 匹配浏览器语言前缀。
  - `src/i18n/locales/{zh,en,ja,ko}.ts` 各放一份 UI 字典；`src/i18n/locales/index.ts` 的
    `uiTables` 汇总；`ui.ts` 的 `t(key)` 按 `uiTables[locale] ?? uiTables[DEFAULT]` 取词。
  - `src/content/site.ts`：引入 `tx(lang, {zh,en,ja,ko})` 助手按语言取值，
    `site` 改为 `computed(() => ({ brand: brand(locale.value), nav: nav(locale.value), ... }))`
    直接实时构建整份配置(更干净，无源对象污染)。
  - `src/content/overrides.ts`：`Tr = Partial<Record<Locale,string>>`，每个项目文案补 ja/ko；
    `pickTr` 回退顺序 lang → DEFAULT(en) → zh。
  - `src/content/projects.ts`：`linkLabels`(GitHub/主页/问题反馈/暂无描述) 与 `statusMetaAll`
    均按 `Record<Locale, ...>` 提供 4 语言。
  - 下拉组件 `src/components/LangSelect.vue`：自定义深色下拉，读 `LOCALES`，点击外部/Esc 关闭，
    role=listbox；NavBar 桌面端+移动端均用它替换原按钮组。
- **设备级语言记忆**：`localStorage['hub-develop-locale']` 不变，刷新沿用上次选择。
- **验证**：`vue-tsc` 通过；`vite build` 成功，产物含中/英/日/韩串与持久化 key；已部署
  `gh-pages`(`3f0d9cb`)，线上 `https://hub-develop.top/` 更新。
- **加新语言步骤**：① `LOCALES` 加一项；② `locales/<code>.ts` 放 UI 字典并在 `locales/index.ts`
  汇总；③ `site.ts` 各 `tx(...)` 补该语言、`overrides.ts` 项目文案补、`projects.ts` 的
  `linkLabels`/`statusMetaAll` 补；④ 如需正文兜底，未写的字段自动回退 en→zh。

## Hub-develop 官网：新增繁體中文(zht)，下拉变 5 项(中文/繁體中文/English/日本語/한국어)

- 语言码用 `zht`(`htmlLang='zh-Hant'`)，非 `zh-Hant`/`zh-TW`/...，以保持 2~3 字母码风格。
- `detectLocale` 增加繁体优先识别：`/hant|tw|hk|mo/.test(nav)` 命中即返回 `zht`，
  早于通用 `zh` 判定(否则 `zh-tw` 会被 `startsWith('zh')` 误判成简体)。
- `tx()` 与 `pickTr` 回退顺序：lang → en(DEFAULT) → zh；zht 缺译时先落 en 再落 zh。
- `site.ts` 每个 `tx()` 补 `zht` 键；`overrides.ts` 全部 6 个项目的 name/tag/summary/
  description/highlights 补 `zht`；`projects.ts` 的 `statusMetaAll`/`linkLabels` 补 `zht` 条目。
- 类型安全：`Locale` 由 `LOCALES` 推导，缺 `zht` 处 `vue-tsc` 直接报错(已是天然校验)。
- 已部署 `gh-pages`(`1270dd9`)，`main` 提交 `c1f5367`。
- ⚠️ 之前漏记：`LangSelect.vue` 在 `src/components/` 下，是深色自定义下拉(role=listbox)。
